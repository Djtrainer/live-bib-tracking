# The Jetson Orin Nano race environment (JetPack 7.2.1 / L4T r39.2.1, CUDA 13.2,
# Python 3.12, TensorRT 10.16, system OpenCV 4.8 with GStreamer). Captured
# 2026-09-11 from the .venv the Jetson numbers in JETSON_NOTES.md were
# measured with. NOT a plain `pip install -r`: read the steps.
#
# 1. The venv must see JetPack's TensorRT, CUDA and OpenCV bindings:
#        python3 -m venv --system-site-packages .venv
#
# 2. torch/torchvision come from PyTorch's cu130 index, pinned with the
#    +cu130 local tag so pip cannot substitute PyPI's CPU-only aarch64 wheel
#    of the same version (it did: manylinux tags outrank linux_aarch64).
#    pypi.jetson-ai-lab.io has no JetPack 7 channel for Orin; its sbsa/cu130
#    torch is built for sm_110/sm_121 only and cannot launch a kernel on an
#    sm_87 Orin. The official cu130 wheels carry sm_80 SASS, which runs here.
#        .venv/bin/pip install --index-url https://download.pytorch.org/whl/cu130 \
#            --extra-index-url https://pypi.org/simple "torch==2.9.1+cu130"
#        .venv/bin/pip install --no-deps --index-url https://download.pytorch.org/whl/cu130 "torchvision==0.24.1"
#
# 3. ultralytics and easyocr declare pip OpenCV dependencies that would
#    shadow JetPack's GStreamer/hardware-decode cv2, so install them --no-deps
#    and their other dependencies explicitly. numpy stays at the system 1.26.4:
#    JetPack's cv2 was built against numpy 1.x. Never install opencv-python or
#    opencv-python-headless into this venv; confirm with
#        python -c "import cv2; print(cv2.getBuildInformation())" | grep -i gstreamer
#        .venv/bin/pip install --no-deps ultralytics==8.3.176 easyocr==1.7.2
#        .venv/bin/pip install -r requirements-jetson.txt
#
# 4. Build the engines on this board: scripts/export_tensorrt.py.
